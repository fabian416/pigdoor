# Pigdoor

**Credit that only pays out when the condition is met.**

Pigdoor locks a [Lendoor](https://github.com/LuchoLeonel/lendoor-stellar) loan in a Soroban escrow
and releases it to the supplier only when the evidence checks out. If anything is missing, the
money stays put.

Built at [HackMeridian 2026](https://www.hackmeridian.com/build), Scale category.
